# На столе

Общее приложение для ресторанов с отдельными меню по адресу `/r/<адрес>`. Витрина использует CSS-перспективу и фотографии блюд. Администраторы управляют собственными меню в кабинете. Владелец платформы создаёт рестораны и назначает или отзывает доступ по Gmail.

## Локальный просмотр

С Node.js 24 выполните `node local.mjs` и откройте `http://127.0.0.1:4173`. Рестораны и меню создаются в кабинете `/admin`. Для локального входа запустите `node --env-file=.env local.mjs` и добавьте в Google Cloud URI `http://127.0.0.1:4173/auth/google/callback`. Сервер хранит локальные записи и фото в `.menu-data/`.

## Сборка и настройка

1. Выполните `node build.mjs`. Точка входа Cloudflare Worker появится в `dist/server/index.js`.
2. Подключите постоянное объектное хранилище Cloudflare R2 с именем привязки `BUCKET`.
3. Создайте OAuth-клиент типа Web application в Google Cloud и добавьте точный URI перенаправления `https://<домен>/auth/google/callback`.
4. Установите серверные переменные `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` и `OWNER_GMAIL`. Секрет Google храните в настройках окружения хостинга.
5. Откройте `/admin` и войдите через Google с адресом владельца. Создайте ресторан, назначьте администратора по Gmail и передайте ему ссылку `/admin`. Гостям отправьте ссылку меню `/r/<адрес>`.

Для доступа гостей и внешних администраторов домен должен пропускать их к приложению. Приложение проверяет Google-аккаунт и права администратора на сервере. Для OAuth-приложения в тестовом режиме добавьте аккаунты сотрудников как тестовых пользователей.
