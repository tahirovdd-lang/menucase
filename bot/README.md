# Бот MenuCase

Платформа BotHost, язык Python 3, ветка `main`, главный файл `bot/main.py`. В карточке бота укажите токен Telegram. BotHost передаст его процессу как `BOT_TOKEN`.

Команда `/start` открывает ссылки на опубликованное меню и кабинет ресторана. Для уведомлений о регистрациях в окружении сайта задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_ID`. Отправка уведомлений выполняется сервером сайта. Откройте личный чат с ботом и нажмите Start, чтобы бот мог писать администратору.
