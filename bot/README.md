# Бот MenuCase

На BotHost укажите Python 3, ветку `main` и точку входа `main.py`. Укажите токен в карточке бота. BotHost передаст его как `BOT_TOKEN`.

В личном чате с ботом выполните `/start`. Для уведомлений о новых ресторанах задайте в окружении сайта `TELEGRAM_BOT_TOKEN` (секрет) и `TELEGRAM_ADMIN_CHAT_ID`. После регистрации ресторан сохраняется на сайте, а уведомление отправляется в чат системного администратора.
